# Luxe Studio

Concept de site pentru un salon de înfrumusețare premium, cu atmosferă întunecată și accente aurii.

## Ce conține

- Rezervare online pe servicii
- Pagini pentru echipă, galerie, servicii și contact
- Animații de intrare cu Framer Motion
- Versiune în română și engleză

## Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router · Framer Motion

## Rulare locală

```sh
npm install
npm run dev
```
